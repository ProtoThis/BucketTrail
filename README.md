# BucketTrail

**BucketTrail** is a self-hosted travel bucket list and trip planner that helps you collect places you want to visit, organize them into adventures, and keep everything in one simple map-based overview.

Instead of losing ideas in bookmarks, notes, and screenshots, BucketTrail gives you one place to save destinations, attractions, restaurants, hotels, and activities for future trips.

---

## Features

### Save places

- Add locations directly on the map
- Search places using OpenStreetMap
- Organize locations into categories:
  - See
  - Do
  - Eat & Drink
  - Hotel & Sleep

### Plan trips

- Group places into trips and adventures
- Create day trips or multi-day journeys
- Add notes and target dates
- Track visited locations

### Interactive maps

- View all places on a map
- See which locations belong to a trip
- Quickly navigate between destinations

### Self-hosted

- Run everything in a single Docker container
- SQLite database for easy backups
- No subscriptions
- Your data stays yours

---

## Why BucketTrail?

BucketTrail was created to solve a common problem:

> "I have dozens of places I want to visit, but they are scattered across bookmarks, emails, screenshots and notes."

BucketTrail combines:

- Travel bucket lists
- Trip planning
- Place collections
- Family adventure ideas

into one simple application.
